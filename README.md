# Vetunix

API de consultas veterinárias desenvolvida para a disciplina de Engenharia de Software II. Permite agendar, listar, buscar e cancelar consultas, com cálculo de preços, descontos e taxas de cancelamento. Os dados são armazenados em memória.

## Tecnologias

Node.js, TypeScript, Express, Jest, ts-jest, Supertest e Docker.

## Execução

Use Node.js 22 ou superior.

```powershell
git clone https://github.com/alefedeveloper/Vetunix-API.git
cd Vetunix-API
npm ci
npm run build
npm start
```

A API escuta na porta 3000. Use `npm run dev` para executar a demonstração.

## Testes

```powershell
npm test
npm run test:coverage
```

O relatório HTML de cobertura fica em `coverage/lcov-report/index.html`.
